# 天津

## 表

要：《国网天津市电力公司代理购电工商业用户电价表》的分时电度电价（尖峰 / 高峰 / 平时段 / 低谷，按当月表头）。
不要：执行 1.5 倍代理购电价格表；《代理购电价格信息表》；「其中」组成项（代理购电价格、上网环节线损费用折价、电度输配电价、系统运行费用、政府性基金及附加）；非分时电度电价列；容（需）量。

## 行分类

用电分类均为工商业用电 → `GENERAL_COMMERCIAL`。单一制 → `SINGLE_PART`；两部制 → `TWO_PART`。不要再拆用户小类。

## 电压

- 不满 1 千伏不要出档、不要并入 `LEVEL_1_10`
- 1–10 千伏 → `LEVEL_1_10`（无单独 20 千伏行，不要出 `LEVEL_20`）
- `35千伏-110千伏（不含）` → `LEVEL_35`
- `110千伏-220千伏（不含）` → `LEVEL_110`
- `220千伏及以上` → `LEVEL_220_PLUS`

单一制、两部制表上若有「不满 1 千伏」行，都跳过，不要并入 `LEVEL_1_10`。

## 电价列

只读「分时电度电价」分组表头。`平时段` 常与非分时列同值，仍用分时列。单一制通常无尖峰值 → `tipPrice: null`。两部制仅当月表有尖峰列且该月执行尖峰时才填 `tipPrice`。无深谷表头 → `deepValleyPrice: null`。

## 时段出处

主表表注（分时结构说明）。只出该 `yearMonth` 所在季节一套；当月注里执行尖峰则 periods 标 `tip`（一般只落在两部制档）。
