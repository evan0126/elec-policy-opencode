# 湖南


## 表

要：页1《国网湖南省电力有限公司代理购电工商业用户电价表》（执行时间 2026-09-01 至 2026-09-30），取其中「电度电价」列组的当月分时电度电价，表头为 尖峰/高峰/平段/低谷（本月无深谷档）。
不要：页2《执行 1.5 倍代理购电工商业用户电价表》；页3《代理购电价格表》（代理购电价格公示，非到户分时价）；页4《代理购电工商业单一制用户分时平均电价表》（测算用平均价，非到户分时电度价）。也不要「输配电价」列组的 尖/峰/平/谷、「系统运行费用折价」「上网环节线损费用折价」「其他折价」「政府性基金及附加（含容需量）」等组成项。

## 行分类

用电分类 原文「单一制」「两部制」，用户类别均为「代理购电工商业用户」→ `customerCategory` = GENERAL_COMMERCIAL；「单一制」→ `tariffMode` = SINGLE_PART，「两部制」→ TWO_PART。无「一般工商业」单独类别，无「大工业」单独出档。

## 电压

单一制：不满1千伏不要出档、不要并入 LEVEL_1_10；1-10千伏 → LEVEL_1_10；35千伏 → LEVEL_35；110千伏 → LEVEL_110。两部制：1-10千伏 → LEVEL_1_10；35千伏 → LEVEL_35；110千伏 → LEVEL_110；220千伏及以上 → LEVEL_220_PLUS。「不满1千伏」只在单一制出现，跳过；无单独20千伏档；220千伏档原文「220千伏及以上」，映射 LEVEL_220_PLUS。

## 电价列

分时电度价按「电度电价」列组当月表头文字识别：尖峰 → tipPrice、高峰 → peakPrice、平段 → flatPrice、低谷 → valleyPrice，表头叫法无特殊别名。不要用「输配电价」等组成项列的同类 尖/峰/平/谷 数。
