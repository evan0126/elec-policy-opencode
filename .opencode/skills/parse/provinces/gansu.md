# 甘肃

## 表

要：《国网甘肃省电力公司代理购电工商业用户电价表》大表头「分时电度电价」下的高峰 / 平 / 低谷。
不要：组成项（代理购电价格、上网环节线损折价、输配电价、系统运行费用折价、政府性基金及附加）；《代理购电价格信息表》。

## 行分类

均为 `GENERAL_COMMERCIAL`：单一制 → `SINGLE_PART`；两部制 → `TWO_PART`。

## 电压

1–10 / 35 / 110 / 220 及以上按通用映射。不满 1 千伏不要出档、不要并入 `LEVEL_1_10`。无单独 20 千伏行不要出 `LEVEL_20`。两部制若无「不满 1 千伏」行，不要补造。

## 电价列

`高峰时段` → `peakPrice`，`平时段` → `flatPrice`，`低谷时段` → `valleyPrice`。不要用左侧组成项同名「高峰/平时/低谷」列冒充。无尖峰、深谷表头则对应价为 null。

## 时段出处

该电价表下方注释。只出该 `yearMonth` 所在季节一套。

## name

无覆盖。
