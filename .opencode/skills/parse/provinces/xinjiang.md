# 新疆


## 表

要：表1「国网新疆电力有限公司代理购电工商业用户电价表」（执行时间 2026年9月1日—2026年9月30日），取「分时电度电价（元/千瓦时）」下尖峰、高峰、平时段、低谷、深谷五列；表中「—」填 null。
不要：表2「国网新疆电力有限公司执行1.5倍代理购电工商业用户电价表」；表3「国网新疆电力有限公司代理购电价信息表」；「非分时电度电价（元/千瓦时）」列；「其中」电量组成（代理购电价格、上网环节线损电价、电度输配电价、政府性基金及附加、系统运行费折价）；「容（需）量用电价格」（最大需量、变压器容量）。

## 行分类

用电分类栏为「工商业用电」→ `GENERAL_COMMERCIAL`，全表无其他用电分类，无「一般工商业」独立出档。行先按电价制度分「单一制」→ `SINGLE_PART`、「两部制」→ `TWO_PART` 两档，每档内再按电压等级分行；单一制表上有不满1千伏行则跳过、不要并入 `LEVEL_1_10`，两部制自1~10千伏起。

## 电压

不满1千伏不要出档、不要并入 `LEVEL_1_10`（仅单一制表上有此行，跳过）；1~10千伏 → `LEVEL_1_10`；35千伏 → `LEVEL_35`；110千伏 → `LEVEL_110`；220千伏及以上 → `LEVEL_220_PLUS`。无单独 20 千伏档；无「220千伏」单独价（只有「220千伏及以上」）。单一制比两部制多一条不满1千伏（跳过），其余电压两档一致。

## 电价列

专栏头「分时电度电价（元/千瓦时）」，子列别名：尖峰 → `tipPrice`；高峰 → `peakPrice`；平时段 → `flatPrice`；低谷 → `valleyPrice`；深谷 → `deepValleyPrice`（「平时段」为平段特殊叫法）。「非分时电度电价（元/千瓦时）」列数值等于平时段价，不要当独立分时价。当月尖峰、深谷两列均为「—」，对应 `tipPrice`、`deepValleyPrice` 填 null；是否取值由月份例外决定（见时段出处）。
