## 表

要：附表 2《国网江苏省电力有限公司代理购电工商业用户电价表》的分时电度用电价格（尖峰 / 高峰 / 平 / 低谷，按当月表头）。
不要：附表 1《代理购电价格信息表》；「其中」下的组成项（代理购电价格、上网环节线损费用折价、电度输配电价、政府性基金及附加、系统运行费用折价）；左侧非分时「电度用电价格」列；容（需）量电价；1.5 倍说明；电热锅炉两段制。

## 行分类

用电分类均为工商业用电 → `GENERAL_COMMERCIAL`。

- 两部制 → `TWO_PART`
- 单一制「100 千伏安及以上」→ `SINGLE_PART`
- 单一制「100 千伏安以下」：默认不要出档（自行选择分时；与上档电压枚举相同会撞键）。用户点名再另说。

## 电压

`1-10（20）千伏` → `LEVEL_1_10`，不要另出 `LEVEL_20`。不满 1 千伏不要出档、不要并入 `LEVEL_1_10`。其余：35 / 110 / 220 及以上按通用映射。两部制表上无「不满 1 千伏」行，不要补造。

## 电价列

只读「分时电度用电价格」分组表头：`尖峰时段` → `tipPrice`，`高峰时段` → `peakPrice`，`平时段` → `flatPrice`，`低谷时段` → `valleyPrice`。当月无尖峰表头（或该月不执行尖峰）→ `tipPrice: null`。无深谷表头 → `deepValleyPrice: null`。
