# 浙江

## 表

要：《代理购电工商业用户电价表》的分时电度电价。
不要：非分时电度电价列、代理购电价格信息表。

## 行分类

- 两部制（含表头仍写「大工业及一般工商业用电」、同价）→ 出两条：`LARGE_INDUSTRY` + `TWO_PART` 与 `GENERAL_COMMERCIAL` + `TWO_PART`
- `单一制（一般工商业用电）` → `GENERAL_COMMERCIAL` + `SINGLE_PART`

## 电压

`1~10（20）千伏` → `LEVEL_1_10`，不要另出 `LEVEL_20`。不满 1 千伏不要出档、不要并入 `LEVEL_1_10`。其余：35 / 110 / 220 及以上按通用映射。

## 电价列

无覆盖。

## 时段出处

当月公告正文、表注或附件。只出该月所在季节一套；文件另列节假日深谷且用户未点名则不要那套。

## name

无覆盖。
