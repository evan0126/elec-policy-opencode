## 行分类

用电分类均为工商业用电 → `GENERAL_COMMERCIAL`。

- 单一制 → `SINGLE_PART`
- 两部制 → `TWO_PART`

## 电压

按「电压等级」逐行映射；不满 1 千伏不要出档、不要并入 `LEVEL_1_10`（仅单一制有则跳过）。

- `1-10（20）千伏` → `LEVEL_1_10`，不要另出 `LEVEL_20`
- `35 千伏`（单独档）→ `LEVEL_35`
- `35-110 千伏`（合并同价）→ 拆成 `LEVEL_35` 与 `LEVEL_110` 两条
- `110 千伏`（单独档）→ `LEVEL_110`
- `110 千伏及以上`（合并同价）→ 拆成 `LEVEL_110` 与 `LEVEL_220_PLUS` 两条
- `220 千伏及以上` → `LEVEL_220_PLUS`

## 电价列

只读「分时电量电价」分组：尖峰时段 → `tipPrice`；高峰时段 → `peakPrice`；平时段 → `flatPrice`；低谷时段 → `valleyPrice`。无深谷表头 → `deepValleyPrice: null`。不要用左侧组成项或电度电价合计列冒充分时价。

尖峰是否填价：以各表表注该 `yearMonth` 是否执行尖峰为准；当月不执行 → `tipPrice: null`，`periods` 不要出现 `tip`。

## 时段出处

各分区域电价表表下注里写峰谷分时 / 尖峰执行的条文（全省统一时段划分）。只出该 `yearMonth` 实际执行的一套；不要写死钟点。无深谷则 `periods` 不含 `deepValley`。四表时段规则相同则共用一套。
