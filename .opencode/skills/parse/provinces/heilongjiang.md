# 黑龙江


## 表

要：附表 1「国网黑龙江省电力有限公司代理购电工商业用户电价表」（执行时间 2026年9月1日-2026年9月30日）里的**分时电度电价**（尖峰时段、高峰时段、平时段、低谷时段）列。
不要：附表 2「代理购电价格信息表」；非分时电量电价列；「其中」拆分项（代理购电价格、上网环节线损费用、电量输配电价、系统运行费用、政府性基金及附加）；容(需)量电价；注 3 提到的按 1.5 倍的代理购电电价。

## 行分类

用电分类列统一为「工商业用电」，其下分「单一制」「两部制」两组电压档。大工业不再单独出档，并入工商业。
- 单一制 → `customerCategory` = `GENERAL_COMMERCIAL`，`tariffMode` = `SINGLE_PART`
- 两部制 → `customerCategory` = `GENERAL_COMMERCIAL`，`tariffMode` = `TWO_PART`

## 电压

- 不满 1 千伏不要出档、不要并入 `LEVEL_1_10`（仅单一制出现，跳过）
- 1-10(20) 千伏 → `LEVEL_1_10`（20 千伏与 1-10 印在同一格，不另出一条 `LEVEL_20`）
- 35 千伏 → `LEVEL_35`
- 110(66) 千伏 → `LEVEL_110`
- 220 千伏及以上 → `LEVEL_220_PLUS`

## 电价列

分时电度电价（元/千瓦时）列名与模板映射：尖峰时段 → `tipPrice`、高峰时段 → `peakPrice`、平时段 → `flatPrice`、低谷时段 → `valleyPrice`。注 2 说明当月**暂停执行尖峰电价**，故 `tipPrice` 取 `null`，periods 中不要出现 `tip`。表无深谷列，`deepValleyPrice` 取 `null`。
