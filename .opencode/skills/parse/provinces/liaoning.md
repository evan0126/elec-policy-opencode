# 辽宁


## 表

要：《国网辽宁省电力有限公司代理购电工商业用户电价表》（执行时间 2026年9月1日—2026年9月30日）「分时电度电价（元/千瓦时）」组的尖峰、高峰、平时段、低谷列。
不要：《国网辽宁省电力有限公司代理购电价格信息表》（2026年9月）——组成项信息表；「非分时电度电价」列（＝2＋3＋4＋5＋6，非分时合计）；容（需）量用电价格（最大需量、变压器容量）列。

## 行分类

用电分类原文为「工商业用电」，覆盖单一制与两部制，customerCategory 一律映射 GENERAL_COMMERCIAL，无单独「大工业」或「一般工商业」出档。
「单一制」→ SINGLE_PART；「两部制」→ TWO_PART。

## 电压

电压等级只出现四档：不满1千伏 / 1~10（20）千伏 / 110（66）千伏 / 220千伏及以上，单一制与两部制各有这四档。
- 不满1千伏不要出档、不要并入 LEVEL_1_10
- 1~10（20）千伏 → LEVEL_1_10（20 千伏与 1–10 印在同一行，不再另出 LEVEL_20）
- 110（66）千伏 → LEVEL_110（66 千伏与 110 同行并入 110，无单独 66 档）
- 220千伏及以上 → LEVEL_220_PLUS
无 35 千伏档。

## 电价列

分时电度电价组表头：尖峰、高峰、平时段、低谷。
- 尖峰 → tipPrice（2026-09 本列全部为「—」，tipPrice = null）
- 高峰 → peakPrice
- 平时段 → flatPrice
- 低谷 → valleyPrice
无「深谷」列，deepValleyPrice = null；不要用「非分时电度电价」列或「其中」组各分项冒充分时价。

## 时段出处

本 PDF（电价表 + 信息表）通常只给分时电度电价数值、不给具体钟点。分时时段需另取公告正文 / 现行分时电价时段 / 现货市场运营规则，只出该 `yearMonth` 一套；文件不含时段则失败并写明，不要编造。尖峰是否执行以当月表列/表注为准。
