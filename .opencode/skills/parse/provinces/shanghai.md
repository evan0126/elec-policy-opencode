# 上海


## 表

要：当月（执行时间 2026-09-01 至 2026-09-30）「表：国网上海市电力公司代理购电工商业用户电价表」中的「分时电度电价（元/千瓦时）」组（尖峰时段、高峰时段、平段时段、低谷时段、深谷时段）。
不要：表内并排的「容（需）量用电价格」组（最大需量、变压器容量）、「电度电价（元/千瓦时）」下的各项组成拆分（代理购电价格、上网环节线损电价、电度输配电价、其他分摊电价、政府性基金及附加）、信息表。只取分时电度电价组，不要用组成项列冒充分时价。

## 行分类

「用电分类」列全表恒为「工商业用电」。电压等级列内按「单一制」「两部制」分两组。单一制 → `GENERAL_COMMERCIAL` + `SINGLE_PART`。两部制组标注含大工业及一般工商业用电、同价 → 每个电压出两条：`LARGE_INDUSTRY` + `TWO_PART` 与 `GENERAL_COMMERCIAL` + `TWO_PART`。

## 电压

单一制与两部制两组电压档位：不满 1 千伏不要出档、不要并入 `LEVEL_1_10`；10 千伏（原文写「10千伏」，非「1-10千伏」）→ `LEVEL_1_10`；35 千伏 → `LEVEL_35`；110 千伏 → `LEVEL_110`；220 千伏及以上 → `LEVEL_220_PLUS`。表内无单独 20 千伏档，不要生成 `LEVEL_20`。

## 电价列

无覆盖。

## 时段出处

取自表下「备注」里写分时时段的条文。单一制与两部制各一套；两部制若分季节，只出该 `yearMonth` 所属那一套。深谷是否执行以当月备注为准。不要写死钟点。
