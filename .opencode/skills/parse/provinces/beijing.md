# 北京

## 表

要：国网北京市电力公司代理购电价格公示表（分单一制 / 两部制）的分时电度电价。
不要：1.5 倍表、信息表、容需量、组成项。

## 行分类

统一 `GENERAL_COMMERCIAL`。按单一制 / 两部制分档，不要再拆用户小类。

## 电压

不满 1 千伏不要出档、不要并入 `LEVEL_1_10`；1–10 → `LEVEL_1_10`；35–110 同价 → 拆成 `LEVEL_35` 与 `LEVEL_110` 两条，不要 `LEVEL_35_110`；220 及以上 → `LEVEL_220_PLUS`。无单独 20kV 行则不要出 `LEVEL_20`。

## 电价列

峰、平、谷按表头。有尖峰表头用该列；没有则看公告上浮规则，有规则再算 `tipPrice`，没有则 `null`。

## 时段出处

当月公示表注、公告正文或同文件附件。该月执行尖峰则 periods 标 `tip`。

## name

无覆盖。
