# 福建


## 表

要：附表1《国网福建省电力有限公司代理购电工商业用户电价表》（执行时间：2026年9月1日—2026年9月30日）。分时电度电价取「分时电量电价（元/千瓦时）」下的 尖峰时段、峰时段、平时段、谷时段 四列。
不要：附表2《代理购电价格信息表》（明细/计算关系/数值，单位：万千瓦时、元/千瓦时）；「非分时电量电价（元/千瓦时）」列；容（需）量电价两列；1.5 倍（注3：已直接参与市场交易、燃煤自备电厂改由电网企业代理购电等特定用户按上表 1.5 倍执行，无单独 1.5 倍附表）。

## 行分类

用电分类「工商业」→ `customerCategory` = `GENERAL_COMMERCIAL`。电价制度两档：「单一制」→ `tariffMode` = `SINGLE_PART`；「两部制」→ `tariffMode` = `TWO_PART`。无一般工商业单独行，无大工业单独出档。

## 电压

「电压等级」一列，一行一档：
- 不满 1 千伏不要出档、不要并入 `LEVEL_1_10`（仅单一制表上有此行，跳过；两部制无此档，从 1-10（20）千伏起）
- 1-10（20）千伏 → `LEVEL_1_10`（20 千伏与 1-10 印在同一行，不再另出一档 20 千伏）
- 35 千伏 → `LEVEL_35`
- 110 千伏 → `LEVEL_110`
- 220 千伏及以上 → `LEVEL_220_PLUS`

## 电价列

「分时电量电价（元/千瓦时）」下四个时段列：尖峰时段 → `tipPrice`、峰时段 → `peakPrice`、平时段 → `flatPrice`、谷时段 → `valleyPrice`。按该四列表头文字识别，列内数值即为当月分时价（由 尖峰=2×1.8+3+4+5+6 等公式算得），直接取值、不要拆分。
不要用「非分时电量电价（元/千瓦时）」（公式 1=2+3+4+5+6）或组成列（代理购电价格、上网环节线损电价、电度输配电电价、政府性基金及附加、系统运行费折价）冒充分时价。
无深谷列或当月不执行深谷 → `deepValleyPrice` = `null`，`periods` 里不出现 `deepValley`。
