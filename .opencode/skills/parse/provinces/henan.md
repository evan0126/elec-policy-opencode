# 河南


## 表

要：
表 1「国网河南省电力公司代理购电工商业用户电价表」（执行时间：2026年9月1日-2026年9月30日），取其中的分时电度电价（尖峰 / 高峰 / 平时段 / 低谷）。

不要：
表 2「代理购电价格信息表」；分时电度电价下方的代理购电价格、上网环节线损电价、电度输配电价、政府性基金及附加、系统运行费折价；容（需）量用电价格（最大需量、变压器容量）。

## 行分类

用电分类列只有「工商业用电」→ `customerCategory` 取 `GENERAL_COMMERCIAL`。
电价制度在电压等级列上按两组展开：一组「单一制」、一组「两部制」，`tariffMode` 分别取 `SINGLE_PART` / `TWO_PART`，各组之下的电压档各出一条记录。

## 电压

单一制：不满 1 千伏不要出档、不要并入 `LEVEL_1_10`；1-10（20）千伏 → `LEVEL_1_10`；35 千伏 → `LEVEL_35`；110 千伏 → `LEVEL_110`；220 千伏及以上 → `LEVEL_220_PLUS`。
两部制：1-10（20）千伏 → `LEVEL_1_10`；35 千伏 → `LEVEL_35`；110 千伏 → `LEVEL_110`；220 千伏及以上 → `LEVEL_220_PLUS`。
20 千伏印在「1-10（20）千伏」同一行 → 不再单出 `LEVEL_20`；无 35-110 合并档、无单独 220 千伏档（都是 220 千伏及以上）。

## 电价列

分时电度电价列名：尖峰 → `tipPrice`；高峰 → `peakPrice`；平时段 → `flatPrice`；低谷 → `valleyPrice`。
「平时段」即平段，且等于「电度用电价格」列（表内公式 9=1）；取平时电价读「平时段」列，不要拿「电度用电价格」或「电度输配电价」列冒充分时价。
当月「尖峰」列整列为「—」→ `tipPrice` 为 `null`；表无「深谷」列 → `deepValleyPrice` 为 `null`。

## 时段出处

表 1 表注里引用分时电价政策的那条：本文件通常只引文号、未列钟点。时段按该注所引文件抽该 `yearMonth` 所在季节一套；文件不含时段则失败并写明，不要编造或套往年钟点。
