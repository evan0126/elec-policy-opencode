# 贵州

## 表

要：第 3 页《贵州电网公司代理购电工商业用户电价公告表》的「峰谷分时电量电价」列组（高峰时段 / 平时段 / 低谷时段）。

不要：第 4 页《贵州电网公司执行 1.5 倍代理购电价格工商业用户电价公告表》；第 5-6 页《代理购电信息公开表》；第 1-2 页公告正文；「其中」组成项（代理购电价格、电量输配电价、上网环节线损单价、系统运行费用单价、基金及附加）；「电量电价」合计列；容（需）量电价。

## 行分类

用电分类均为工商业用电 → `GENERAL_COMMERCIAL`。

- 单一制 → `SINGLE_PART`，「峰谷分时电量电价」列为空（无分时值）→ 只出「电量电价」作 `flatPrice`（`peakPrice` / `valleyPrice` 为 null，`periods` 全天 flat）
- 两部制 → `TWO_PART`（有分时列值）→ 出档

## 电压

（两部制行）

- 1-10（20）千伏 → `LEVEL_1_10`，不要另出 `LEVEL_20`
- 35 千伏 → `LEVEL_35`
- 110 千伏 → `LEVEL_110`
- 220 千伏及以上 → `LEVEL_220_PLUS`

## 电价列

只读「峰谷分时电量电价」列组：高峰时段 → `peakPrice`；平时段 → `flatPrice`；低谷时段 → `valleyPrice`。无尖峰表头 → `tipPrice: null`；无深谷表头 → `deepValleyPrice: null`。单位已是元/kWh，直接抄。不要用「电量电价」合计列或组成项冒充分时价。

## 时段出处

主表注 2：高峰时段 10:00-13:00、17:00-22:00；平时段 8:00-10:00、13:00-17:00、22:00-24:00；低谷时段 00:00-08:00。无尖峰、无深谷，`periods` 不含 `tip` / `deepValley`。
