# 湖北


## 表

要：顶部「国网湖北省电力有限公司代理购电工商业用户电价表」（执行时间 2026-09-01～2026-09-30）当月分时电度电价（尖峰/高峰/平段/低谷）。
不要：下方「代理购电价格表」（组成项拆分）；本表右侧容（需）量电价（变压器容量、最大需量）；「其中」组成项列。

## 行分类

行头「工商业用电」下按「单一制」「两部制」分两档：
- 单一制 → `GENERAL_COMMERCIAL` + `SINGLE_PART`
- 两部制 → `GENERAL_COMMERCIAL` + `TWO_PART`

## 电压

- 不满1千伏不要出档、不要并入 `LEVEL_1_10`（仅单一制有此行，跳过；两部制无此档）
- 1-10(20)千伏 → `LEVEL_1_10`（20千伏印在同一行，不另出 `LEVEL_20`）
- 35千伏 → `LEVEL_35`
- 110千伏 → `LEVEL_110`
- 220千伏及以上 → `LEVEL_220_PLUS`
