# 河北

## 表

河北行政上一省，电价有两套。本文件只读国网河北省电力有限公司（南网）。冀北待补充，不要套本规则。

要：《国网河北省电力有限公司代理购电工商业用户电价表》的分时电度电价（尖峰 / 高峰 / 平时段 / 低谷 / 深谷，按当月表头）。
不要：执行 1.5 倍代理购电价格表；《代理购电价格信息表》；「其中」组成项（代理购电价格、上网环节线损电价、电度输配电价、政府性基金及附加、系统运行费折价）；非分时电度电价列；容（需）量；转供电主体终端用户电价表。

## 行分类

用电分类均为工商业用电 → `GENERAL_COMMERCIAL`。单一制 → `SINGLE_PART`；两部制 → `TWO_PART`。

## 电压

不满 1 千伏不要出档、不要并入 `LEVEL_1_10`；1–10 / 1~10 → `LEVEL_1_10`；35 → `LEVEL_35`；110 → `LEVEL_110`；220 及以上 → `LEVEL_220_PLUS`。无单独 20 千伏行不要出 `LEVEL_20`。两部制若有「不满 1 千伏」行同样跳过，不要并入。

## 电价列

只读「分时电度电价」分组表头。`平时段` 常与非分时列同值，仍用分时列。无某档表头则该价 `null`。表计在部分月份把深谷显示在尖峰字段，解析仍按表头「尖峰」「深谷」列取值，不要把两列合成一条。

## 时段出处

主表表注（分时浮动与季节说明）。只出该 `yearMonth` 所在季节一套。
