# 省份 id 映射

解析 JSON 的 `province` / `provinceId` **只准抄本表**，不要从电价文件或别称自行发明。

| 列 | 写入 JSON | 含义 |
|---|---|---|
| `id` | `provinceId` | 内部系统省份 id |
| `province` | `province` | 入库用中文短名，不要写成「浙江省」 |

取链栏目、覆盖文件仍用 `sources.md` 的拼音节名（如 `beijing`），**不要**把拼音写进 JSON 的 `provinceId`。用中文名对齐本表。

河北默认本表「河北」（南网 `208`）。行政上是一省，网上国网另有冀北一套代理购电，见未覆盖表，取链待补充，不要用 `208` 冒充。内蒙古默认「内蒙古」（蒙东）。
