# 省份覆盖文件约束

只写**这一份原文怎么读表**。先叠 `common.md`，覆盖文件只写差异。子 agent 解析时读覆盖正文，不必读本约束。

省主覆盖与「另一份原文」覆盖均 **必填**（按 pathMap key 选对应文件）；缺失则该 key 直接失败，不要只靠 `common.md` 硬解。

## 路径

| 路径 | 何时用 |
| --- | --- |
| `provinces/{pathMapKey}.md` | pathMap 每个 key 一篇（省主如 `guangdong.md`，额外原文如 `shenzhen.md`）—**必填**；一律同级 |

- 省主：pathMap key = 省 id（与 `sources.json` 节名相同）
- 另一份原文：pathMap key = `extraSources[].id`（如 `shenzhen`）；`id` 不得与省 key / 别名撞名
- 只用来选覆盖文件；**这份文件出哪些区写在覆盖正文里**

编排选文件（只选**一个**，不要叠两份）：

1. 存在 `provinces/{pathMapKey}.md` → 用它
2. **不存在** → 该 key **直接失败**，提示 `还没有写…的读表规则，请先补 .opencode/skills/parse/provinces/{pathMapKey}.md`；**不要**起解析子会话

两份原文读法不同时必须各写一篇，不要把两套规则写进同一篇。

## 固定排版

标题：省文件用映射表 `province` 短名；分区文件用该区 `regions.md` 的 `label`（如 `广东深圳`）。下面 **六节必须都有、顺序固定**。无覆盖的节写 `无覆盖。` 一行，不要删节。

```
# {中文名或 label}

## 表

## 行分类

## 电压

## 电价列

## 时段出处

## name
```

`## 表` 之前不要另写引言。南网默认、无月度列表等例外，写进 `## 表`。

## 各节写什么

| 节 | 写什么 | 不写什么 |
|---|---|---|
| 表 | 取哪张表/标题；要分时电度电价。另起一行写不要哪些表 | 1.5 倍表、信息表、容需量、组成项（除非点名排除） |
| 行分类 | 原文行头 → `customerCategory` + `tariffMode`；该省特有的出档/跳档 | 抄一遍 `common.md` 枚举表 |
| 电压 | 原文档位 → 模板六档 `LEVEL_*`；合并行是否另出 20kV；不满 1 千伏不要出档 | 并入 `LEVEL_1_10`；`LEVEL_BELOW_1` / `LEVEL_35_110`；把不同价的电压合成一条 |
| 电价列 | 仅当表头叫法特殊时写别名（原文 → `tipPrice` 等） | 第几列、列顺序；用非分时列冒充分时价 |
| 时段出处 | 从哪抽：表注 / 公告正文 / 附件（按「分时/时段划分」内容认）；是否只要当月季节一套 | **具体几点到几点**；**第几条注** |
| name | 无覆盖。 | 自拟政策名；把 `province` 写成「北京市」 |

## 禁止

- 复制 `common.md` 的枚举、数字精度、`periods` 通用约定
- 写死钟点、第几条注，或全年多套季节
- 写 `province` / `provinceId`（只准抄 `province-ids.md`）
- 写取链栏目、网址（那是 `.opencode/skills/fetch-download/sources.json`）
- 把别省规则、样本页码、注释原文搬进来
- 把两份原文的读法写进同一篇（另一份原文用子目录文件）
- 用别名当覆盖文件名（应用 `extraSources[].id`）
